# Задача 20. Три кристалла

## 1. Формулировка задачи
Для открытия портала необходимо зажечь три древних кристалла. Кристалл загорается, если переданная ему энергия (A, B, C) кратна трем. Портал откроется только в том случае, если загорятся все три кристалла одновременно. Программа принимает три целых числа и выводит логический результат проверки.

## 2. Логическая часть
Для проверки кратности числа 3 используется операция взятия остатка от деления:
* Кристалл A загорится, если: `a % 3 == 0`
* Кристалл B загорится, если: `b % 3 == 0`
* Кристалл C загорится, если: `c % 3 == 0`

Итоговое логическое условие для открытия портала требует одновременного выполнения всех трёх условий:
`a % 3 == 0 && b % 3 == 0 && c % 3 == 0`
